# social-assets

Musiques et visuels pour les publications Facebook / Instagram.

## Musiques

Déposer les morceaux (MP3 ou WAV) dans le dossier qui correspond à l'ambiance :

- `musiques/chill/` — doux, posé
- `musiques/dynamique/` — rythmé, énergique
- `musiques/corporate/` — sobre, professionnel

Nommage conseillé : `ambiance-numéro-titre.mp3`, par exemple `chill-01-morning-coffee.mp3`.

Chaque morceau doit être libre de droits pour un usage commercial sur Facebook et Instagram.
Noter sa provenance dans `musiques/LICENCES.md`.

## Publications

Un dossier par publication dans `publications/`, nommé `année-mois-sujet`,
avec les visuels, la vidéo et la légende.
